# Product Requirements

## Problem
General AI can answer children’s questions but does not naturally provide child safety, age calibration, evidence-aware learning, proof of understanding, durable mastery, spaced review or actionable parent participation.

## Child flow
Ask → safety decision → age-aware explanation → optional structured visual → comprehension check → remediation/retry → star/mastery update → Stardust → review schedule.

## Parent flow
Account → verified consent → child profile → limits → curiosity summary → fading topics → safety center → family rewards → privacy/export/delete → billing.

## Surfaces
Child: Ask, Lesson, Quiz, My Sky, Constellations, Review Orbit, Stardust.
Parent: Overview, Curiosity, Review, Safety, Rewards, Profiles/Limits, Privacy, Billing.
Admin: Safety queue, Eval quality, Evidence quality, Prompt/Policy versions, Cost/Latency, Abuse, Release certification.

## Non-goals
No ads/behavioral targeting, public child profiles, infinite engagement loops, raw voice retention by default, or pretending generated content is inherently factual.

## Production factual-output acceptance
Input policy passes; reading level fits; evidence references exist in trace; unsupported confidence is avoided; structured output validates; output safety/age checks pass; cost/latency budgets pass.
